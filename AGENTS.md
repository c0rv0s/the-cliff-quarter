# Project guidance

- For gameplay, feel, audio, menus, or live features, load `craft-game-floors`. If missing, ask before running `unity skill install <client>`.
- Keep the limestone, terracotta, turquoise, olive, brass, and blue-shadow palette in `Setup/ProjectBrief.md`.
- Target this MacBook: compact routes, URP, 1080p, no real-time GI. Measure native performance before claiming 60 fps.
- Preserve `RiverCityBaseline.unity`; develop the playable city in a separate scene.
- Use GitHub and Railway CLIs outside the sandbox. Keep docs and comments concise.
