# Tiny World

Unity foundation for a Mediterranean cliff-city parkour sandbox.

## Open

Open the `TinyWorld` folder in Unity 6000.6.9f1.
The starting scene is `Assets/Scenes/RiverCityBaseline.unity`.
Press Play to view the scene. Movement is not implemented yet.

## Next milestone
